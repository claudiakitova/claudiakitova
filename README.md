I'm Claudia Kitova. I work with physics, data and astronautics.

What I'm building:

- [lifekeeper](https://github.com/claudiakitova/lifekeeper): a method and a tool for collecting your own data (photos, chats, posts) into one archive on your computer, and asking it questions.
- [moon-base-fire-evidence](https://github.com/claudiakitova/moon-base-fire-evidence): an open dataset and dashboard of NASA microgravity combustion tests, made for NASA Space Apps 2026.
- [physics-talks](https://github.com/claudiakitova/physics-talks): a chatbot that answers condensed matter physics questions from a library of scientific papers. [Try it](https://physics-talks.streamlit.app).
- [ask-your-db](https://github.com/claudiakitova/ask-your-db): upload documents and ask questions about them, with page sources. [Try it](https://ask-your-db.streamlit.app).
- [data-stories](https://github.com/claudiakitova/data-stories): study projects in data science.
